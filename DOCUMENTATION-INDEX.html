1

Install & Run Locally (2 min)

Clone the repo, install dependencies, and run on localhost:3000. See detailed instructions in QUICK-START.md

2

Test with Sample Data (5 min)

Use 12 provided problem statements to generate artifacts. Test all features: export, edit, history, settings

3

Verify Quality (5 min)

Run npm run build, type-check, and lint. Check Lighthouse scores (target: >90)
