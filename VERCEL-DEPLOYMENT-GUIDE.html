⏱️ Expected Time: 5-10 minutes total
📋 What You'll Need: GitHub account, Vercel account (or create one)

Step 1: Go to Vercel Dashboard

First, visit Vercel's website to create a new project.

  1. Open your web browser
  2. Go to: https://vercel.com/new
  3. You should see the "Create New Project" page
💡 Not logged in? Click "Sign in" or "Sign up" first. You can use your GitHub account to sign in.

Step 2: Import GitHub Repository

Tell Vercel to import the repository containing the enhanced HTML.

  1. On the "Create New Project" page, you'll see: "Import Git Repository"
  2. Click the search box under "Import Git Repository"
  3. Copy and paste this URL:
    https://github.com/shiv12-art/ai-product-copilot
  4. Press Enter or click Search
  5. Click "Import" on the repository card
⚠️ Make sure: You see "ai-product-copilot" in the results, not a different repo

Step 3: Configure Project Settings

Set up the project with the correct configuration.

  1. Project Name: Change it to:
    ai-product-copilot-enhanced
  2. Framework Preset: Select "Other" (it's static HTML, not a specific framework)
  3. Root Directory: This is important! Click the dropdown and select:
    ai-product-copilot-enhanced

    This tells Vercel to deploy from the correct folder

✅ Correct settings:
• Project Name: ai-product-copilot-enhanced
• Framework: Other
• Root: ai-product-copilot-enhanced

Step 4: Review & Deploy

Review your settings and deploy the project.

  1. Scroll down and review the settings one more time
  2. Click the "Deploy" button
  3. You'll see a loading screen with "Building and deploying..."
  4. Wait for the build to complete (usually 30-60 seconds)
  5. You'll see a checkmark and "Congratulations!"
🎉 Deployment Complete!
You'll see a unique URL like: ai-product-copilot-enhanced-abc123.vercel.app

Step 5: Verify Your Deployment

Test that everything is working correctly.

  1. Copy the URL provided by Vercel (something like ai-product-copilot-enhanced-xyz.vercel.app)
  2. Open it in a new browser tab
  3. Check for the "✨ Enhanced Edition" badge in the top-right
  4. Test one category - try Healthcare:
    • Enter: "AI mental health chatbot"
    • Select: Healthcare
    • Click: "Generate All 7 Artifacts"
    • Verify you see: Dr. James Wilson & Teladoc as competitor
✅ If you see the Enhanced Edition badge and Healthcare-specific content, you're done!

📋 Final Verification Checklist

🔧 Troubleshooting

Issue: Build failed

  • Make sure Root Directory is set to ai-product-copilot-enhanced
  • Check that Framework is set to "Other"
  • Try redeploying by clicking "Redeploy" in the dashboard

Issue: Still seeing old version

  • Wait 5 minutes (Vercel CDN caching)
  • Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  • Try incognito/private window

Issue: Missing the enhanced badge

  • Check you're on the NEW enhanced URL, not the original
  • Original URL: ai-product-copilot-a358.vercel.app (unchanged)
  • New URL: ai-product-copilot-enhanced-[xxx].vercel.app (new)
